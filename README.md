## 📖 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos da linguagem **Java**, utilizando entrada de dados pelo teclado, métodos, estruturas condicionais e cálculos matemáticos.

A aplicação realiza o cálculo do salário líquido de um funcionário a partir do salário bruto e dos descontos informados pelo usuário.

Além disso, o sistema classifica:

* 💰 Faixa salarial
* 📊 Percentual de desconto
* 🧮 Total de descontos
* 📈 Salário líquido

---

# ✨ Funcionalidades

✔ Cadastro do funcionário

✔ Cálculo do total de descontos

✔ Cálculo do salário líquido

✔ Cálculo do percentual de desconto

✔ Classificação da faixa salarial

✔ Classificação do desconto

✔ Exibição formatada dos resultados

# 📋 Regras de Negócio

## Faixa Salarial

| Salário Líquido   | Classificação  |
| ----------------- | -------------- |
| Até R$ 2.000      | 🟡 Baixa renda |
| Até R$ 5.000      | 🟢 Média renda |
| Acima de R$ 5.000 | 🔵 Alta renda  |

---

## Percentual de Desconto

| Percentual   | Classificação     |
| ------------ | ----------------- |
| Até 10%      | 🟢 Desconto Baixo |
| Até 20%      | 🟡 Desconto Médio |
| Acima de 20% | 🔴 Desconto Alto  |
